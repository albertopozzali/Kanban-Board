# MyKanban — Progetto Scolastico

**MyKanban** è una scheda Kanban digitale sviluppata come progetto scolastico per la gestione semplice ed efficace delle attività personali e di gruppo. Permette di organizzare il flusso di lavoro suddividendo i compiti in categorie visive intuitive.

## Cos'è una Kanban Board e come funziona MyKanban?

Il metodo **Kanban** è un sistema di gestione visiva del lavoro nato per ottimizzare i flussi di attività. **MyKanban** applica questi principi all'interno di un'interfaccia web pulita e immediata.

### Struttura
**MyKanban** si suddivide in colonne che rappresentano lo stato di avanzamento dei lavori:

1. **To Do (Da Fare):** Contiene tutti i task, le idee o le consegne che devono ancora essere iniziate.
2. **In Progress (In Corso):** Accoglie le attività su cui si sta lavorando al momento. Serve a mantenere il focus ed evitare di accumulare troppi compiti contemporaneamente.
3. **Done (Completato):** Raccoglie tutti i task portati a termine con successo.
